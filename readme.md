# Adarsh Pathak — Portfolio (v1)

Personal portfolio of a Python Full Stack Developer, built with only HTML, CSS and vanilla JavaScript.

**Live:** https://mradarshpathak-dev.github.io/portfolio/

## Features
- Responsive layout (mobile, tablet, desktop)
- Sticky navbar with mobile menu and active-link highlighting
- Scroll reveal animations
- Contact form with client-side validation (backend not connected yet)

## Structure
index.html · style.css · script.js · assets/images/

## Run locally
Open `index.html` in a browser. No build step.
